# Uttar Buniyadi Ashram Shala — Digital Campus System

## GitHub Pages ready
This folder is intentionally a **static GitHub Pages build**.

- `index.html` is in the root.
- `logo.png` is in the root.
- No Node.js, npm, React build or backend is required to run this demo.
- Data entered in the demo is stored in the browser's localStorage.

## Demo login
### Student
- Roll: `1` to `80`
- Standard 9 password: `student9`
- Standard 10 password: `student10`

### Teacher
- Any 10-digit mobile number
- Password: `teacher`

## GitHub Pages
1. Create a GitHub repository.
2. Upload **the contents of this folder**, not the outer folder itself.
3. Make sure `index.html` is directly visible in the repository root.
4. GitHub → Settings → Pages → Deploy from branch → `main` → `/ (root)` → Save.
5. GitHub will show the live Pages URL.

## Important
This is a GitHub Pages demo/static version. The original Node/Express/SQLite backend is not included in the live static flow. For real authentication, persistent student data, real AI answers, teacher database access and secure complaints, connect a backend such as Render/Railway/Supabase later.
